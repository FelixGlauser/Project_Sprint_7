# Project_Sprint_7

## Descripción del proyecto

Este proyecto realiza un análisis exploratorio de datos de anuncios de vehículos usados y desarrolla una aplicación web interactiva con Streamlit.

La aplicación permite visualizar los datos mediante gráficos interactivos de Plotly.

## Funcionalidades

La aplicación incluye:

- Un histograma para visualizar la distribución del kilometraje.
- Un gráfico de dispersión para analizar la relación entre el kilometraje y el precio.
- Botones para generar los gráficos de forma interactiva.
